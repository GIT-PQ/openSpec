# 致谢

随着这篇硕士论文完成，我的学习生活也要告一段落，在这期间有苦有乐，从最初的迷茫到不断地改进自己的方案，每一点进步都离不开我的指导老师、师兄师姐以及家人的关心帮助。

首先，我想对我导师**教授表示由衷地感激之情，在论文初稿撰写、模型设计、代码调试以及最后定稿过程中都得到**老师的悉心指导，在此谨向**老师表示衷心感谢。是**老师认真负责的工作态度，扎实渊博学识以及对待每一个环节一丝不苟精神让我明白什么是真正的学者风范并学会如何做一个学者。其次，我还需要对指导我平时学习生活、工作中遇到问题时提供帮助和指导的**副教授表示诚挚谢意。两位老师对我指导和帮助使我在学术之路上更加坚定信心。

再次，感谢一路上陪伴我的各位同门，在实验室一起研究学习，也曾在科研之外参与各种各样的事务，在相互鼓励之间激发思想，在日常生活当中建立友情的美好时光，给这段困难重重的学习生涯带来很多快乐，也是我研究生生涯中最珍贵、最耀眼的回忆。

另外，我也要特别感谢远在中原的亲人们。你们或许并不了解我每天接触的各种各样的算法以及数据，但是你们对我的关心、理解和全力支持，都是我学习生活中最重要的依靠，是你们的无私奉献让我能够专心致志投入到我的学业中去写成这篇论文。

最后，向所有参加本论文评阅、答辩的各位老师表示衷心感谢，在百忙之中对我论文审阅并提出许多有益建议。

凡是过往，皆为序章。带着这份感谢和期盼，我将迎接人生新的旅程。祝愿各位老师身体健康，工作顺利，祝愿各位同学前程似锦，万事顺遂！
